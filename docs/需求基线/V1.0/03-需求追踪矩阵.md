# 个人博客网站 V1.0 需求追踪矩阵

## 使用说明

- US 是主要需求组织单位，FR 表示为实现该用户故事需要提供的功能。
- 编写 SPEC 后填写“SPEC 章节”。
- 开始开发后填写任务编号、提交记录或实现位置。
- 完成验收后填写测试用例或检查结果。
- 实现状态使用：未开始、进行中、待验收、已完成、已延期。
