# 个人博客网站 V1.0 需求基线包

本目录是个人博客网站 V1.0 的正式需求基线。自 2026-10-10 起，设计、SPEC、开发、测试和验收均以本目录中的 PRD V1.0 为准。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `01-个人博客网站PRD-V1.0.md` | 已评审通过的正式产品需求文档，是需求主体 |
| `02-需求基线记录.md` | 记录基线编号、范围、结论和版本规则 |
| `03-需求追踪矩阵.md` | 将 US、FR 关联到 SPEC、开发任务和测试结果 |

持续变化记录位于上级目录的 `需求变更记录.md`，不在本目录中维护，避免修改已冻结的历史基线。

## 使用规则

1. 本目录建立后不再直接修改。
2. 编写 SPEC 时以 PRD 第 05 章为主体，同时引用角色权限、数据规则、非功能需求和交互要求。
3. 在需求追踪矩阵中填写对应的 SPEC 章节、开发任务和验收记录。
4. 需求发生变化时，先登记到上级目录的《需求变更记录》，再建立新的 PRD 草案。
5. 新版本确认后建立新的基线目录，例如 `V1.1`。
