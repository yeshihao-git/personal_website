## 维护规则

1. 需求发生变化时先在本文件登记。
2. 简单变更直接在台账中记录，不需要为每个变更建立独立文件。
3. 接受变更后，从当前基线 PRD 复制一份新的草案，不直接修改基线文件。
4. 同步评估 SPEC、页面、数据、权限、开发任务、测试和发布范围的影响。
5. 新版本确认后建立新的基线目录，并更新“当前有效基线”。
